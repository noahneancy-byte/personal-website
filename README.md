# 我的个人网站

一个使用纯 HTML / CSS / 原生 JavaScript 构建的个人网站，采用 Refero「Steep」编辑部极简设计风格。

## ✨ 特点

- 编辑部杂志式极简主义（Steep 设计系统）
- 墨黑 + 纸白 + 桃色点缀的克制配色
- 衬线大标题 + 无衬线正文的排版体系
- 药丸形按钮、24px 圆角卡片、发丝级边框
- 响应式设计，适配手机与桌面端

## 🚀 本地预览

直接用浏览器打开 `index.html` 即可，无需任何构建工具。

## 📁 目录结构

```
个人网站/
├── index.html   # 页面主文件（含样式与脚本）
└── README.md    # 项目说明
```

## 🛠 技术栈

- HTML
- CSS（Source Serif 4 + Inter 字体）
- 原生 JavaScript
